ROYAL QR PACK
1. index.html ko kisi free static host par upload karo (GitHub Pages, Netlify, etc.).
2. Hosting ke baad jo public URL mile, us URL ko QR mein use karna hoga.
3. Abhi QR images mein YOUR-USERNAME.github.io placeholder hai, isliye upload URL milne ke baad QR dobara generate karna zaroori hai.
4. Page par ?caste=saini / kashyap / thakur / bhimrao / jatav se alag screen khulti hai.
